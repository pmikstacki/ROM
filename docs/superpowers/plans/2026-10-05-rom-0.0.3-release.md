Ruling: The listed UX/backend messages define release acceptance, not optional post-release polish. This prevents another premature completion.
Ruling: Standard temporal/decimal controls must validate at the backend. Browser input widgets alone cannot establish valid persisted semantics.
Ruling: Datetime canonical ordering must agree with the generic query comparator. Use a fixed UTC representation rather than arbitrary preserved offsets.
Ruling: Work remains a snapshot inspector until an authorized history source exists. Do not fabricate a timeline from attempt counts.
Ruling: Favicon ownership is explicit under the Studio base path. The neutral R is a placeholder, not a newly approved branding system.

Ruling: A deleted seeded Resource must remain deleted after restart. Bootstrap must not replay a create receipt for an existing tombstone.
