Resource code is in `author/src/{model,actions}.rs`; its crate root contains declarations and exports only.
The StockCode codec trims and canonicalizes uppercase. It rejects empty and non-ASCII strings and wrong JSON shapes.
AuditNote uses the typed public Resource reference contract.
The explicit `RESTORE_STOCK` compensation runs after the original domain result is known, with a separate key and current revision.
Compensation replay creates no second Resource event. It is never inferred from an unknown operator outcome.

The native fixture is a local owner type in `author/tests/native/fixture.rs`; no orphan implementation is required.
It owns fresh private directories, bounded name retries and its SQLite handle.
The runner's reopen succeeds only when that handle has strong count one.
Profile 0 fails at `profile.version` before any factory call.
Deliberately incorrect facts fail at `storage.bundle.counts` with an Assertion category and static safe error.
Codec cases supply input, canonical output and expected typed value separately.

The operator handle is generated and validated through public protocol types.
`operator/fault.mjs` bounds the child wait, response capture, HTTP body and server lifecycle.
It checks exactly one submission, no diagnostic disclosure of private fixture markers, and exact request-file preservation.
`operator/diagnosis.md` retains version, epoch, key, hash and concrete later commands.
The fixture's ephemeral endpoint has been closed; it is not a recovery endpoint.

## Actual author errors and corrections

1. The first Resource compile failed because `Resource` was missing from the action module imports for `Inventory::KIND`.
   Adding the trait import resolved the error. The failed source and log are retained.
2. The first operator oracle required the literal word “unknown.” The CLI correctly printed “mutation outcome unresolved.”
   The oracle was corrected to the actual uncertainty contract; no product change was made.
3. The first release attempt ran host-worktree Git from the container. Its `.git` metadata points to a host-only path.
   Host preparation created the archive; container Cargo inspected the extracted source. Both attempt logs remain.
4. The fixture used `AtomicU64::fetch_update`, deprecated on the declared Rust 1.99 floor.
   Strict Clippy rejected it. The fixture now uses `try_update`; the failed and corrected runs remain.

These are actual agent/tooling assumptions, not fabricated product failures or proof that a skill fixes them.
Early guesses of non-existent documentation/source paths were replaced with repository searches.
The initially unavailable conformance API and guide were not scored as workflow failures.
The native attempt waited for meaningful codec/storage positive and negative tests to pass.
Optional blob implementation was still pending and was not exercised.
