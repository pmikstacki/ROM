## Implementation

`rom-conformance` is a development-only consumer of public ROM interfaces.
Its crate root contains module declarations and exports only.
Named modules own profile admission, safe error categories, Field vectors, storage scenarios, and optional blob assertions.
The `blob` Cargo feature adds only the existing `rom-blob` dependency.

The exact required public signatures are implemented.
The coordinator also approved `storage::for_profile(version, factory)` and `storage::assert_bundle(storage, facts, previous, bundle)`.
`for_profile` admits the assertion profile before factory invocation.
`assert_bundle` checks the documented fresh-store two-commit baseline, with counts `[1, 2, 2, 2]`.
It is not an assertion for arbitrary history.

Storage factories create two fresh exclusive fixtures: direct atomic bundle operations and typed Runtime operations.
The runner checks replay, fingerprints, stale revisions, no-op validity, ordered events and effects, and reopen.
It drops storage clones and shuts down and drops Runtime owners before reopen.
Native and external fixture owners reject reopen while an Arc clone survives.
`StorageFacts` counts mean rows, events, receipts, and effects, in that order.
The facts method remains a trusted test seam, not a production Storage method or an authorization boundary.

Field vectors supply input, canonical JSON, and expected typed value independently.
The helper checks rejected vectors and canonical decode/encode stability.
It does not claim complete descriptor/shape verification of arbitrary codec code.
Existing Resource registration, custom/manual equivalence, and runtime negatives retain that separate layer.

Blob assertions preserve the existing folder/S3 contract: immutable create, race arbitration, bounds, empty objects, and idempotent deletion.
They require a disposable exclusive namespace with a sixteen-byte adapter limit.
They do not promise cleanup after an arbitrary failing adapter or cover general provider recovery.

The self-contained guide and JSON manifest record profile revision 1, source compatibility, version owners, and mismatch obligations.
Resource-owned custom codecs remain the current alpha boundary.
Independent Field identity, registry, and collision guarantees remain absent; the broader proposal stays open.
Native format 8 and archive format 6 are unchanged.
