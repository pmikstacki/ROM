## Admission and ownership

One canonical asset inventory serves assembly and admission.
Admission compares the complete inventory, per-file hashes, workflow catalog, source identity, and lock metadata.
It rejects obsolete profiles, missing features, removed feature requirements, substituted assets, omitted indirect hashes, changed source, missing assets, broken links, and unsafe paths.
The source identity covers workspace Cargo.toml/Cargo.lock and `.rs`/Cargo.toml files under crates, demo, and examples.
It excludes `tests/persistence`, unrelated scripts, and other checkout files.
This is the selected input identity, not a whole-checkout hash.
It does not require a Git checkout or contain a hard-coded developer path.

Trusted example commands own a Linux process group.
The runner applies a 180-second default deadline and a one-MiB output bound.
Timeout or output overflow triggers group TERM, group KILL after 500 milliseconds, and a final bounded pipe-close fallback after 2.5 seconds.
The live negative starts a TERM-ignoring descendant with inherited pipes and proves bounded return with no live descendant.
This is trusted subprocess ownership, not a sandbox against commands that deliberately escape the group.
