## Findings during CLI implementation

1. **A raw HTTP error cannot prove rollback.** Coordinator review traced arbitrary `ActorGate` errors through observation after `invoke_row` has committed. Even categories such as Conflict or TooLarge can arrive after a durable mutation. The accepted correction treats every unsuccessful response after submission as unresolved; local preflight errors and read/stream rejection remain distinct. This avoids changing core policy semantics or inventing a phase-bearing protocol. A real post-commit gate regression is required before closure.
2. **Responses must match the requested Resource identity and history.** Independent TCP reproduction made the working CLI request `tasks/requested-id` and returned a structurally valid success for `other-kind/other-id`. Both read and mutation incorrectly exited successfully and printed that unrelated view. A separate reproduction accepted a journal response that changed the requested generation and moved position 100 back to 1. Contextual validation must reject these before output: read protocol failure or unresolved mutation. Streams must retain and validate their previous accepted cursor, while preserving legitimate filtered gaps and empty batches.
3. **Interrupts must not wait for stderr.** With a mutation awaiting its response and stderr connected to a live but full buffer, SIGINT left the client running because its signal task logged synchronously before exiting. The interrupted outcome must be reported by exit status even when the diagnostic destination is blocked; the diagnostic must be best-effort and bounded. The regression must observe actual exit rather than merely killing the child during test teardown.

These findings concern an in-progress CLI, not the released MVP. All were corrected in CLI source `1d7a640`, integrated as `1d1d622`. The independent reviewer executed all 26 CLI tests and re-ran the three original TCP/process reproductions against review source `66864f2`: wrong identity returned read exit 4 / mutation exit 5 with no stdout, changed/backward cursors returned 4 with no stdout, and full-stderr interruption returned 130. The real post-commit ActorGate regression also passed; even the `not_committed` category is labelled without asserting rollback. See the [final independent report](core-cli-independent-review.md) and [combined release evidence](core-cli-results.md). No P1/P2 finding remains open.
