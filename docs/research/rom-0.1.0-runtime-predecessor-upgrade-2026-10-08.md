# Accepted Runtime and custom-codec replay trial

Date: 2026-10-08. Status: executed compatibility subset; full release admission remains open.

The preceding accepted-writer trial checks complete storage state.
It does not establish replay of commands generated by the actual predecessor Runtime.
This separate trial adds that proof. It does not replace the stronger whole-state trial.

## Test contract

The application declares a string field with codec identity `upgrade-ticket-code`, version 1.
Its decoder trims whitespace and converts letters to uppercase.
The accepted Runtime creates a Resource, changes the custom field, and invokes a typed action.
The action changes quantity and produces one stored effect.
The writer retains three actual receipts, three events, one row, and one effect.
No test invents receipt fingerprints or rewrites storage format markers.

The current adapter upgrades the native source into a separate destination.
The current Runtime repeats the three original commands with the original keys, revisions, and principal.
Each result must match the predecessor result, including the custom codec value.
A conflicting request with the original action key must return `Error::IdentityMismatch`.
After policy revocation, the original principal must receive `Error::Denied` for each original command.
Rows, receipts, events, effects, descriptors, and references must remain unchanged after these attempts.
The source database and original archive must remain byte-identical.
Both SQLite and redb must pass.

## Limits

The historical writer uses public Rust APIs from verified source.
It does not establish installed-package adoption, production identity, external delivery, or full application rollback.
Those release requirements remain separate.
The maintained test is explicitly ignored unless historical evidence is supplied.
These tests establish this historical Runtime replay subset. They do not establish compatibility outside its declared application codec and commands.
Full application cutover, rollback, independent review of this new trial, and final packaged release verification remain open.
