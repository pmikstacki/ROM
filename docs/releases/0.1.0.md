# ROM 0.1.0

Date: 2026-10-10. Status: experimental source release.

## Publication decision

The owner authorized publication before the remaining verification gates passed.
This decision does not change a failed result into a passed result.
The standard release verifier remains unchanged.
This source release does not establish production readiness.

GitHub hosts the source and the `v0.1.0` tag.
Registry publication remains disabled.
The existing VPN preview has separate deployment evidence; this tag does not certify an updated preview.

## Changes in this source release

- Captured validators support runtime-owned state through the Resource contract.
- Public Studio controls and shared UI helpers support external Svelte applications.
- Shared installation layouts have explicit package and license ownership checks.
- Generic mutation recovery preserves request identities and distinguishes unknown outcomes from confirmed failures.
- Durable work, projections, backup, upgrade and diagnostics have additional implementation and test fixtures.
- Optional AI modules add provider-neutral routing, OpenRouter integration, typed tools and durable agent flows.
- AI flow changes separate timeout phases and preserve settlement and recovery boundaries.
- Human OIDC operations renew a short-lived proof before handoff and verify current authority again.
- The auth changes retain original JWT expiry, stream authority and post-publication unknown-outcome behavior.

These changes retain the Resource/action/event model.
The domain core remains independent of concrete database and transport drivers.
The [consumer research plan](../research/rom-0.1.0-consumer-research-plan.md) records the intended scope and acceptance criteria.
The [coordination record](../research/rom-0.1.0-coordination.md) identifies the implementation work.

Those results do not replace complete verification of this tag.

The retained trial reached 9,575 successful HTTP responses and 11,681 completed groups.
It also recorded five denied responses, three unknown outcomes and 3,366 producer admission refusals.
The target workload did not pass.
Producer admission, proof lifetime and database costs remain investigation areas, not confirmed explanations for every failure.

Private waiting-producer experiments and later runner drafts are not published as accepted framework behavior.

Historical failures and private evidence remain preserved locally.

## Deployment boundary

Treat this tag as experimental.
Before production deployment, run `./scripts/check` and the documented application, recovery, upgrade and load acceptance.
Use an isolated copy of application data for upgrade and restore trials.
Keep a previous application release and a verified backup.
Do not interpret a timeout or an unknown outcome as proof that a mutation did not commit.

The [support boundary](../release-support.md) describes the existing contracts.
Historical acceptance in that document does not certify this source release.
