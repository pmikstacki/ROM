# Release ROM 0.0.2 with generic Studio

## Why

The native release established the Resource contract. Studio must make that contract usable through a real browser application.
The previous mock did not prove generic rendering, human authentication, or integrated recovery.

## What Changes

- Add authorized action-input metadata and a generic browser SDK.
- Build reusable Svelte and shadcn-svelte forms, tables, query editors, and administration views.
- Add an optional Rust Studio host with real human authentication and protected sessions.
- Verify recovery, current authority, lifecycle, and author ergonomics through complete journeys.
- Produce version 0.0.2 artifacts and a persistent VPN preview with fixed acceptance gates.

## Impact

Core changes concern public descriptors and their conformance, not frontend dependencies or transport-specific rules.
Studio, its optional host, local tests, release tooling, documentation, and skills change.
The release identifier intentionally precedes the previous alpha's numeric version. Preserve existing artifacts and document package compatibility.
Preserve native format 8 unless a tested implementation requires an explicit upgrade. Never silently reinterpret receipts or pending work.
The owner authorized autonomous execution and release without additional approvals.
